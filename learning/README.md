# Learning route

The sole educational anchor is **John Watrous, _The Theory of Quantum Information_ (Cambridge University Press, 2018)**, using §§4.3 and 5.1–5.2 on majorization, entropy, relative entropy, data processing and Pinsker's inequality. The [author's book page](https://jhwatrous.github.io/books-and-courses.html) supplies the reading version.

Start with the [Watrous-to-project bridge](ANCHOR_BRIDGE.md). It translates the book's notation and base-two logarithms, works through a complete three-qutrit swap, and supplies the thermodynamic and arithmetic steps needed for the minimum-block question. It then connects the same entropy tools to the comparison between actual and effective harmonic Hamiltonians. No additional educational source or full-book reading is assumed.

The [30-milestone map](MILESTONES.md) develops the common understanding targets. Its 12 background milestones connect states, operations, entropy and occupation statistics to the exact resource question. Its 18 narrative milestones join productive type shifts, typical matching, inherited CWT necessity and QWA sufficiency, irrational calibration, matched detuning, evidence and resource limits. Dependencies and source pointers are supplied for every target.
