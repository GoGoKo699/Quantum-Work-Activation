# Learning route

The educational anchor is **Francesco Campaioli, Felix A. Pollock and Sai Vinjanampathy, _Quantum Batteries_**, using the fixed [arXiv:1805.05507v1](https://arxiv.org/abs/1805.05507v1) review chapter. Its work-extraction section introduces the objects needed here: cyclic unitary driving, passive states, ergotropy and the collective equal-entropy Gibbs benchmark.

Start with the [anchor-to-project bridge](ANCHOR_BRIDGE.md). It identifies the relevant part of the chapter, translates its notation, works through a concrete qutrit example, and explains the additional steps needed for the minimum-block question. The charging-power and implementation sections are not prerequisites for this route.

The [30-milestone map](MILESTONES.md) sets out the project's common understanding targets. Its background phase connects individual states and operations to the collective work problem. Its narrative phase connects occupation shifts, typical probability, useful spectral approximants and passive witnesses to the main result, calibration statement and physical interpretation. Dependencies and source pointers are supplied for every target.

| Reading intention | Route |
|---|---|
| Understand the physical question and the anchor's notation | [Bridge](ANCHOR_BRIDGE.md), then [model](../science/model.md) |
| Build the whole conceptual story | [Milestones](MILESTONES.md), following the dependencies |
| Inspect the proofs directly | [Scientific guide](../science/README.md) |
| Check the examples and reproduce the data | [Numerical report](../verification/report.md) and [commands](../verification/README.md) |
| Identify inherited results and the contribution's scope | [Related work](../references/RELATED_WORK.md) and [interpretation](../science/interpretation.md) |

The map is a guide to understanding the complete contribution. Specialist details remain in the proof pages. The one-third fraction, retained logarithmic gaps, matched-preparation calibration model and distinction between mean-work block size and reliable total output remain part of the learning route.
